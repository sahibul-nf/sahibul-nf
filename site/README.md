# Sahibul NF — Portfolio

Personal portfolio for **Sahibul Nuzul Firdaus** (Flutter & Golang engineer).

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- Framer Motion
- Netlify (Forms + deploy)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Root `netlify.toml` sets `base = "site"` and publishes `dist`.
